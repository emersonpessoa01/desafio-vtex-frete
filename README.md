# 🚚 Simulação de Frete - Desafio VTEX IO

![VTEX IO](https://img.shields.io/badge/VTEX-IO-E31C79)
![TypeScript](https://img.shields.io/badge/TypeScript-5+-3178C6?logo=typescript)
![GraphQL](https://img.shields.io/badge/GraphQL-API-E10098?logo=graphql)
![Status](https://img.shields.io/badge/status-completed-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

Uma solução desenvolvida para a plataforma VTEX IO, implementando um bloco customizado de simulação de frete na PDP (Product Details Page), com foco em performance, acessibilidade, arquitetura escalável e experiência do usuário.

## 📌 Visão Geral

- Integração com GraphQL (vtex.store-graphql)
- Simulação de frete diretamente na PDP
- Consolidação automática entre carrinho e SKU atual
- Máscara e sanitização de CEP
- Estados de carregamento
- Interface responsiva
- Acessibilidade com ARIA
- Desenvolvimento 100% em TypeScript

## 📦 Tecnologias

- VTEX IO
- TypeScript
- React
- GraphQL
- CSS Modules
- VTEX Toolbelt

## ⚙️ Como Executar

```bash
vtex login
npm install
vtex link
```
